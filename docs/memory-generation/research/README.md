# 基于 Agent Trace 生成记忆：调研索引

调研日期：2026-10-09（第四阶段方向 4 补充于 2026-10-10）

本目录汇总"基于 Agent Trace 生成记忆"的调研。研究问题是：从可观测平台已存的 agent trace 中有策略地批量生成记忆，供产生这些 trace 的 agent 在后续任务中使用，目的是避免重复错误、复用已验证做法、遵循用户偏好，场景优先 code agent 与 data agent。调研分四个阶段，检索截至 2026-10-09（第四阶段方向 4 截至 2026-10-10），覆盖论文、开源实现源码、产品文档、规范与公开数据集统计。调研结果按主题分为三份可独立阅读的报告，每份报告都包含概要、问题与术语、调研方向与过程、正文、综合分析与倾向、证据边界和来源。

## 跨报告的主要发现

1. 分组后一次性归纳、并行提议后层次合并优于流式反复合并：并行提议加层次合并 65.83%、约 3 分钟，逐条顺序更新 61.83%、约 60 分钟（Trace2Skill）；流式反复合并比整池一次合并低 17–38 个百分点（2605.12978）。见《生成方法调研》第 4.5、4.8.4 节。
2. 写入前的验证门控（候选条目或修订生效前的验证与准入判断）在技能、harness 与 prompt 演化研究中已普遍采用，在可检索经验条目的生成与产品中仍是少数做法：15 组有 / 无门控消融方向一致（均为作者自报），其中 5 组去掉门控后低于或持平于基线，例如 OpsHarness 末段 0.33 低于不演化的 0.43、Crystallization 无门控的卡片库比无记忆低 2.03 个百分点；验证集过小时门控近似噪声过滤（Recuris），验证消耗可占优化预算的一半。产品以"建议 + 有权限者确认"（Hex、Snowflake Cortex Analyst、Databricks Genie）或"使用时校验 + 未用过期"（Copilot、Codex）代替写入前自动验证。只有离线 trace 时，可用的验证信号为对照源 trace 的依据校验、trace 内已记录的执行侧信号、跨会话与跨用户的独立支持数、历史 trace 上的影子回放与时间切分。见《生成方法调研》第 4.8.6 节、《信号与选样调研》第 5.9、7.7 节、《输入、存储与评测调研》第 8.5.2 节。
3. agent 自述与同源自评不能作为结果信号：Open-SWE-Traces 上失败轨迹自述成功的比例（47.6%）高于成功轨迹（39.2%）；步骤级自动归因在长日志上为 3.5%–8.8%，接近随机基线 4.2%（Who&When）。见《输入、存储与评测调研》第 9.4 节、《信号与选样调研》第 5.1、5.4 节。
4. 对单一 agent 与模型，任务结果主要由任务本身决定：同 instance 分组中只有 12.2% 的组成败并存，放宽到同 repo 后新增对比大多混入难度差异；去掉具体实体的 LLM 任务抽象在未见任务上损失最小。见《信号与选样调研》第 4.4–4.6 节、《输入、存储与评测调研》第 9.2 节。
5. 一次性主张被写成偏好会传播：PASB 中主张被写入记忆的运行后续失败率 71.9%，未写入为 45.0%（观察分组）；把偏好编译为工具调用前后的校验比注入上下文合规率高 15 个百分点（TRACE）。见《信号与选样调研》第 6.3、6.7 节。
6. 开源实现均先把 trace 压平为文本，溯源最细到 span_id（altk-evolve）且在合并后丢失；《生成方法调研》表 4-2 收录的 74 项工作中，未见以多层 span 树为输入或以 span 为溯源锚点的工作。见《生成方法调研》第 4.8.5、5.4、5.5 节、《输入、存储与评测调研》第 7.4 节。
7. 撤销与删除需在检索层与派生产物上生效：只在存储层标记失效时旧条目仍会被检索并主导决策，删除源数据需按派生图级联。见《输入、存储与评测调研》第 7.7 节。
8. 自动构建与检索的记忆在编码任务上多数没有收益：VibeMemBench 中 12 组有 11 组未超过无记忆基线；任务依赖前序会话独有证据（DreamBench-SWE）或写入前经过整理与环境探测（Grounding Agent Memory）时，有记忆显著优于无记忆。已报告增益多在 1–5 个百分点，与单次 pass@1 的运行间波动（2.2–6.0 个百分点）相当，检出需要上千个配对运行（估算）；评测需要把内容质量、检索质量与端到端效用分开测。见《输入、存储与评测调研》第 8.3、8.5、8.8 节。
9. 生成记忆的模型按部署形态分化：会话内即时写入由会话模型完成；后台与离线流水线把生成模型与会话模型解耦，默认配置集中在"廉价档模型逐条抽取、中档或强模型跨会话整合"（Codex 阶段一 `gpt-5.6-luna`、阶段二 `gpt-5.6-terra`；13 个给出默认值的开源组件中 8 个默认 mini / haiku 档）。更强的生成模型通常带来更好的记忆，收益随使用方能力递减；生成时能否看到执行经验比生成模型的强弱影响更大（SkillsBench 中不看执行经验的自生成技能约 −1.3 个百分点）。见《生成方法调研》第 4.8.7、5.6 节、《信号与选样调研》第 5.10 节、《输入、存储与评测调研》第 6.6 节。
